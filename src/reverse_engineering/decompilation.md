## Java

Online tool: <https://jdec.app/>.

CLI tool:
- <https://www.kali.org/tools/bytecode-viewer/>: Kali meta-package containing multiple Java tools, such as bytecode viewer and GUI fernflower decompiler.
- <https://github.com/JetBrains/fernflower>: GitHub repository for the fernflower decompiler.
